# Homebrew tap for Velvet

[Velvet](https://github.com/subhashhhhhh/Velvet) is a native YouTube client for macOS that uses little memory.

```bash
brew install --cask subhashhhhhh/velvet/velvet
```

Velvet updates itself (Settings › About, or Velvet › Check for Updates…), so `brew upgrade` leaves it alone.

The cask's version and checksums are updated by Velvet's `scripts/release.sh` on each release.
